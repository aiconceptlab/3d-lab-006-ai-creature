AI CONCEPT LAB // PLAY 001 — AI Creature

A tiny fox. A sleepy lilac bunny. A mischievous cat.
You describe the companion, then meet it in an animated 3D playground.

Nova starts as an AI reference image. Tripo turns it into a textured 3D model, adds a quadruped rig and a walking animation. Jev can choose small behaviours; a local controller handles movement. A supported phone browser provides the room camera and floor tracking.

Throw a virtual ball. Invite it to follow your phone. Let it explore a small play area.

The default Nova is a real generated, animated 3D asset. The cover is concept artwork; swipe for the actual app capture. Other key-free pet designs use labelled procedural shapes. Optional Tripo generation uses credits. Real furniture physics and physical phone validation remain future work.

Source code + setup guide are free. New Tripo generation and Jev API usage may cost credits. The included Nova needs no generation credits to play. The local demo runs without an API key.
