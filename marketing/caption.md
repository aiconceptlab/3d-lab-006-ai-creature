AI CONCEPT LAB // PLAY 001 — AI Creature

A tiny fox. A sleepy lilac bunny. A mischievous cat.
You describe the companion, then meet it in an animated 3D playground.

The concept: Jev interprets the design and chooses small behaviours. A 3D controller handles movement. A supported phone browser provides the room camera and floor tracking.

Throw a virtual ball. Invite it to follow your phone. Let it explore a small play area.

This is a POC with a supported set of creature shapes. The cover is concept artwork; the app uses stylised procedural 3D. Real furniture physics and unrestricted text-to-3D generation are future work.

Source code + setup guide are free. Jev API usage may cost credits. The local demo runs without an API key.
